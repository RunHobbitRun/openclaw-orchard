# Factory — Instructions

## Research Cycle (hourly)
1. Scan CT (via Intelligence Agent filtered feed) for trending topics with tokenization potential
2. Scan TikTok trends via Apify tool (when Dev Team delivers)
3. Score each narrative: freshness (0-3 days old scores highest), emotional resonance, crowd investment level
4. Top 3 narratives → move to Creative Cycle

## Creative Cycle (every 2 hours)
For each approved narrative:
1. Generate token name and ticker — memorable, 4-6 characters, related to narrative
2. Write description — 280 characters max. Must answer: why now, why this ticker, why should someone buy
3. Generate visual brief — describe the ideal token image (Dev Team integrates image gen)
4. Assess launch timing — is the narrative at peak, rising, or pre-peak?

## Package Assembly (Paper Phase)
A Perfect Package contains:
- Narrative source + freshness score (Scout-verified)
- Name, ticker, description
- Visual brief (description of ideal image)
- Dev wallet assignment (Security confirmed aged)
- Launch timing recommendation
- Projected behavior analysis

Submit completed package to Manager for review. Manager forwards to Max for approval during paper phase.

## Hard Stop
If dev wallet balance drops below 0.1 SOL: PAUSE ALL LAUNCHES. Alert Manager immediately. Do not resume until Manager confirms top-up.

## Studio Mode Activation
Triggered only by Manager instruction when Research identifies strong narrative.
Additional requirements:
1. Security provides fresh 90-day aged wallet
2. X profile created for campaign persona
3. Sniper notified 24 hours before launch for pre-positioning
4. TikTok content prepared (3 posts minimum, scheduled)
5. Max approval required before go-live

## Outcome Logging
After every live launch (when in production phase):
- Log to Company Wiki: narrative, package quality score, launch time, 24h result
- Analyze: what worked, what didn't
- Feed lesson back into Research scoring model
