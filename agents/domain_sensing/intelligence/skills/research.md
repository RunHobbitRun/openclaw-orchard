# Deep Research & Knowledge Skills

Provides tools for performing deep web research and querying the internal Obsidian knowledge vault via MCP.

## Deep Research Tool
Uses NotebookLM MCP to perform high-fidelity web research on a specific topic.
```bash
node shared_instruments/scripts/deep_research.mjs "Research Topic"
```

## Knowledge Query Tool
Uses Obsidian MCP to search the `openclaw-knowledge` vault.
```bash
node shared_instruments/scripts/query_knowledge.mjs "Search Term"
```
